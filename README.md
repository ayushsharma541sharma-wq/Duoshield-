# DuoShield - End-to-End Encrypted Messaging App

A production-ready Android app featuring:
- Firebase Anonymous Authentication
- Firestore real-time messaging
- AES-256-GCM end-to-end encryption
- SQLCipher encrypted local database
- FCM push notifications

## Build

The APK is automatically built using GitHub Actions on every push to `main`.

Download the compiled APK from the [Actions artifacts](https://github.com/ayushsharma541sharma-wq/Duoshield-/actions).

## Setup

1. Set the `GOOGLE_SERVICES_JSON` secret in repository settings
2. Push to `main` to trigger the build
3. Download the APK from Actions artifacts
